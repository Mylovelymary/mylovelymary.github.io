# Аптечка 💙

Бесплатная интерактивная «аптечка первой психологической помощи» при панических
атаках, тревоге и тяжёлых днях. Без регистрации, без рекламы, без платных версий.
Работает на телефоне, планшете и компьютере, после первого визита — без интернета.

## Идея

Почти все существующие приложения — на английском, с регистрацией или подпиской
(«АнтиПаника» — единственный заметный русский аналог, и у него платная полная версия).
Аптечка — полностью бесплатная альтернатива, собранная не по методичкам, а по
опыту реальных людей, переживших ПА (статья Dashenzia на irecommend + комментарии,
сообщества r/panicattacks и др.).

Главные принципы:

- **Человек в панике щёлкает, пока не найдёт своё.** Режим SOS показывает
  упражнения по одному, кнопка «Не то, дальше» всегда под пальцем.
- **Дыхание и 5-4-3-2-1 — в самом низу.** По опыту людей их советуют везде,
  но многих они бесят и не работают. Они остались (всем помогает разное),
  но никогда не лезут первыми.
- **Своя аптечка.** Звёздочка ★ на любом упражнении добавляет его в личный
  набор — эти упражнения показываются первыми, порядок настраивается на
  странице «Моя аптечка». Можно добавлять собственные фразы поддержки.
  Всё хранится в localStorage — никаких серверов.
- **Работает офлайн.** PWA c сервис-воркером: можно установить на домашний
  экран и открывать в метро/самолёте. Инструкция — на странице «/install».

## Структура

- `src/data/exercises.js` — база из 26 упражнений: тексты, категории, состояния,
  порядок выдачи. Новое упражнение = запись здесь (+ компонент, если интерактивное).
- `src/components/exercises/` — интерактивные компоненты (метроном похлопываний,
  EMDR-шарик, таймеры, игра «шарики», дверь перед паникой и т.д.).
- `src/app/sos/` — режим SOS (колода «щёлкай дальше»), состояние через хэш
  (`/sos#panic|anxiety|thoughts|low`).
- `src/app/my/` — конструктор личной аптечки.
- `src/app/help/` — бесплатные телефоны психологической поддержки.
- `public/sw.js` — офлайн-кэш (при добавлении упражнения дополни список EXERCISES там же).

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:3000
npm run build    # статическая сборка в out/
```

Сборка — полностью статическая (`output: 'export'`), деплоится на любой бесплатный
хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Достаточно отдать папку `out/`.

## Важно

Аптечка помогает пережить острый момент, но не заменяет психотерапию и врача.
На видном месте — ссылки на бесплатные горячие линии.
